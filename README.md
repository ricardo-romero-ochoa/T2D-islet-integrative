# T2D-islet-integrative

Cross-platform integrative transcriptomics pipeline for the paper "Transcriptomic Architecture of Type 2 Diabetes in Human Pancreatic Islets:
An Integrative Meta-Analysis and Machine Learning Framework for Biomarker Discovery" using:

- GSE25724
- GSE20966
- GSE38642
- GSE164416

## Study objective

Identify conserved transcriptional programs of human islet dysfunction in T2D, derive interpretable refined modules, and generate manuscript-ready figures.

## What is included in this GitHub bundle

- accession-aware GEO import and metadata curation
- per-study preprocessing, gene mapping, and differential expression
- random-effects meta-analysis with leave-one-out sensitivity analysis
- Hallmark/ssGSEA pathway scoring with compatibility for new and old `GSVA` APIs
- initial discovery modules and refined manuscript-grade core modules
- refined module score tables and effect-size summaries
- a figure script that generates **Figures 2–6**

## Repo layout

- `R/_shared.R`: shared helpers and configuration
- `R/01_data_import.R`: GEO download/import
- `R/02_metadata_curation.R`: accession-specific metadata parsers
- `R/03_preprocessing_gene_mapping.R`: preprocessing and probe/gene mapping
- `R/04_within_study_differential_expression.R`: study-level DE
- `R/05_cross_study_meta_analysis.R`: gene-level meta-analysis + LOO sensitivity
- `R/06_pathway_scoring_consensus.R`: GSVA/ssGSEA scoring and Hallmark consensus
- `R/07_module_construction.R`: discovery-stage module construction
- `R/08_beta_cell_specificity_analysis.R`: beta-cell preservation summary
- `R/09_anchor_cohort_depth_analysis.R`: anchor cohort (GSE164416) trend analysis
- `R/10_figures_tables.R`: legacy exploratory figure script kept for reference
- `R/11_sensitivity_analyses.R`: sensitivity summaries
- `R/12_refined_module_scores.R`: refined manuscript-grade module scores and effect-size tables
- `R/13_make_figures_2_to_6_refined.R`: manuscript figures 2–6
- `R/run_all.R`: full end-to-end execution
- `R/run_first_pass.R`: checkpointed execution with logging

## Important notes

1. Do **not** pool raw expression values across studies. This repo fits each dataset independently and combines evidence at the effect-size and pathway-consensus levels.
2. `GSE164416` is imported from the supplementary HTSeq count file for DE analysis and stored separately from the normalized matrix used for scoring.
3. `GSE20966` is used primarily as a beta-cell specificity/preservation cohort.
4. `GSE164416` is the anchor cohort for secondary-state analyses.
5. The discovery modules in `R/07_module_construction.R` are retained for transparency, but the **final manuscript figures and tables use the refined modules**.
6. Example result tables are included for convenience, but the intended use is full regeneration from code.
